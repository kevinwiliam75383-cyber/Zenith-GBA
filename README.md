
# Zenith GBA

Emulador de Game Boy Advance para Android.

## Características previstas

- Compatibilidad con Android 9 o superior.
- Soporte ARM32 y ARM64.
- Motor de emulación mGBA.
- Biblioteca de juegos GBA.
- Controles táctiles personalizables.
- Guardado y carga de partidas.
- Interfaz en español.

## Desarrollo

Proyecto desarrollado desde Android.
